# IncidentHub API v1

## Problema solucionado
La organización reportaba incidentes tecnológicos (equipos que no encienden, fallas de conectividad, problemas de impresión) a través de canales informales como llamadas y mensajes, perdiendo la trazabilidad. IncidentHub API centraliza el registro, consulta, modificación y atención de estas novedades mediante una arquitectura profesional por capas.

## Tecnologías utilizadas
* Node.js
* Express
* TypeScript
